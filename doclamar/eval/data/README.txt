Sample data files for evaluation. Replace with your real outputs.

Files:
- sample_gt_mrr.json: ground-truth relevant doc ids per query
- sample_res_mrr.json: retrieved doc id lists per query
- sample_gt_parsing.json / sample_pred_parsing.json: chunk texts per document
- sample_runs.json: pipeline run logs
- sample_refs.json / sample_hyps.json: reference and hypothesis summaries
- sample_pred_labels.json: predicted cluster labels for demo
- sample_embeddings.npy: optional embeddings file; if missing the runner generates synthetic embeddings
